# Kiara Arcade

Enam game edukasi tentang PJU tenaga surya di Dusun Kiarakoneng 1, untuk pameran KKN Kelompok 7 Pi7ar Cahaya, KKN-D ITB 2026.

| Game | Isi |
|---|---|
| Kiara Dash | Lari dan sambar panel surya |
| Kiara Drive | Menyetir malam, kejar cahaya PJU |
| Kiara Stack | Susun tiang PJU yang lurus |
| Kiara Beam | Arahkan sinar ke panel surya |
| Kiara Tilt | Cari sudut panel terbaik |
| Kiara Lab | Simulasi dan kuis cara kerja PJU |

## Struktur

```
index.html   lobi
css/         tampilan
js/          lobi, musik, ilustrasi, kontrol
games/       enam game
assets/      logo, maskot, font
```
